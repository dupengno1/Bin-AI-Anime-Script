## 重要道具

- **阴阳案录**：泛黄册子，记载九世追凶记录，沈无名随身携带
- **古铜扳指**：顾廷渊右手无名指，纹路与案发现场碎镜完全吻合
- **铜钱（顾字）**：第一世证物，沈无名一直保存至今
- **1990年代录音机**：第八世沈明临死前藏入草丛，现世被沈无名挖出
- **九世祭坛**：顾廷渊在废弃仓库建造，九格已满八格，第九格刻"判官归位"
